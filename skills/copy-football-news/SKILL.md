# Редактура, эмодзи и оформление

1. **Текст новости (`write_copy.py`):**
   - Пишет Gemini по фактам статьи. При коде 0 `copy.json` готов.
   - При коде 3 роль пишет текст сама (`engine: cursor`): жирный заголовок (до 120 знаков), факты без воды, точные `bold_spans` (цифры, счёт, сроки или ключевое имя), цитата без кавычек или `quote: null`. Без рекламы.
2. **Custom emoji (`place_emoji.py`):**
   - Разрешены только 4 пака: `FC_logos` (гербы клубов), `RestrictedEmoji`, `foot_flags_by_fStikBot`, `NewsEmoji`.
   - Клубные эмодзи ставятся в заголовок только при совпадении клуба со статьёй.
3. **Голос болельщика / опрос (`write_voice.py`):**
   - Решает, уместна ли реакция болельщика или интерактивный опрос к новости.
   - При опросе используются разрешённые эмодзи реакций (`RestrictedEmoji`).
4. **Рендер HTML-подписи (`render_caption.py`):**
   - Собирает `caption.html` с Telegram-разметкой (`<b>`, `<blockquote>`, `<tg-emoji>`). Длина поста до 1000 символов UTF-16.

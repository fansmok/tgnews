# Футбольные новости в Telegram

Пайплайн выпускает одну короткую новость мирового футбола в канал. Рекламный час он не перебивает: следующий пост ставится отложенным ровно на минуту, когда реклама должна уйти вниз.

Механику выпуска делает `scripts/pipeline.py` без модели. Агенты (`agents/`, копия в `.cursor/agents/`) тратят токены только там, где нужен смысл.

## Как устроен выпуск

1. `pipeline.py gate` — реклама и слот. Если слот ещё рано, выпуск заканчивается сразу, агенты не запускаются.
2. `pipeline.py scout` — новости за день, память, дедупликация.
3. `pipeline.py produce` — параллельно: текст через Gemini, гербы, голос и подпись; фото, карточка Nano Banana 2.1 (до 4 попыток, затем обычное фото 600×600) и машинное ревью.
4. **fn-critic** (агент) — смысловая проверка текста против источника, фото и гербов. При REWORK `pipeline.py rework` переписывает текст Gemini по замечаниям или пересобирает карточку.
5. `pipeline.py publish` — отправка сразу или отложка user-сессией (Telethon) ровно на минуту слота; перед отправкой сверка с лентой и отложкой канала.
6. `pipeline.py finish` — сводка трудностей и чистка. **fn-fixer** (агент) зовётся только если были трудности.

**fn-copy** (агент) пишет текст только если Gemini недоступен.

Без рекламы — **4 поста в день**: 9:30–10:30, 13:30–14:30, 16:30–17:30 и 19:30–20:30 по Москве. Утро одним прогоном ставит их отложенными. Реклама перестраивает день и добавляет перебития одним прогоном, сразу на все новые слоты:

```text
Реклама сегодня
11:00
15:00
21:40 транса
```

С 11:00 до 12:00 канал молчит, новость выходит в 12:00. То же для 16:00 и 22:40. Подпись «транса» на время не влияет.

Утро готовит все свободные слоты дня и откладывает каждый на свою минуту. Рекламный триггер за один заход готовит все недостающие перебития. Отложенная минута — и у обычного поста, и у перебития.

## Откуда берутся новости

Из RSS, потому что у ленты есть время и обычно есть картинка, а выпуск не зависит от чужого телеграм-канала.

- BBC Sport Football
- The Guardian Football
- Marca
- ESPN Soccer
- Sports.ru, раздел футбола
- Чемпионат, раздел футбола
- Sky Sports

РПЛ без иностранного клуба, хоккей, НБА и прогнозы со ставками отбрасываются. Свой список каналов можно дописать в `shared/sources.json` в `telegram_channels`: сейчас сборщик читает только RSS.

## Custom emoji

Разрешены только `RestrictedEmoji`, `foot_flags_by_fStikBot`, `NewsEmoji` и `FC_logos`. Id подтягиваются командой `python3 scripts/sync_emoji.py`, когда в окружении есть токен бота. Расшифрованные гербы клубов лежат в `shared/fc-logo-tags.json`; чужой или неподписанный герб gate не пропустит.

Custom emoji публикует Premium-аккаунт: используйте `PUBLISH_BACKEND=user` и вход через `scripts/login_user.py`. Строка сессии хранится только в `.env`.

## Что нужно положить в секреты

Скопируйте `.env.example` в `.env` локально или заведите те же имена в Cursor Dashboard → Cloud Agents → Secrets.

- `TELEGRAM_BOT_TOKEN` — бот-админ канала с правом публиковать
- `NEWS_CHANNEL_ID` — `@канал` или id `-100...`
- `ADS_CHANNEL` — публичный `@канал` с расписанием рекламы
- `PUBLISH_ALLOW=yes` — только когда можно публиковать по-настоящему
- `PUBLISH_BACKEND=bot` или `user`
- `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_STRING_SESSION` — для закрытого рекламного канала и для публикации от Premium-пользователя
- `GEMINI_API_KEY` — текст новости и комментарий. Если ключ пустой или API не ответил, эти две роли пишут моделью Cursor

Пока `PUBLISH_ALLOW` не `yes`, `publish.py` делает сухой прогон и ничего не отправляет.

Голос комментария включён: `shared/voice.md`, душа канала @sportonkp. Реплика не обязательна на каждой новости.

## Репозиторий и Cursor Cloud

- GitHub: [github.com/fansmok/tgnews](https://github.com/fansmok/tgnews)
- Облако: подключите этот репозиторий в Cursor (Settings → Git / Cloud Agents), секреты — **Dashboard → Cloud Agents → Secrets** (имена из `.env.example`, значения не в git).
- После правок: `git push` на ветку, которую указали в Automation (обычно `main`); следующий Cloud Agent подхватит новый коммит.
- Перед коммитом после правок агентов: `python3 scripts/sync_cursor_tree.py` (синхронизация `agents/` → `.cursor/agents/`).

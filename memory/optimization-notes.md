# Что ещё можно улучшить

Фиксер ведёт этот список. Сюда попадает то, что повторяется или жрёт токены, но ещё не починено. Секреты не писать.

## Уже сделано 2026-10-22

- Custom emoji берутся только из четырёх разрешённых паков; расшифрованные клубные гербы ставятся автоматически.
- Все карточки 600×600.
- Истории постов и слоты старше 2 дней удаляются при проверке дубля.
- Жирное имя в абзаце без цифры. Короткие фамилии вроде Диас считаются дублем в тот же день.
- Полную карточку собирает Nano Banana 2.1 в 1K по контент-борду. Повтор с неизменными входами переиспользует готовый результат и не тратит новый кредит KIE.
- Шаблон main в промпте карточки требует бейдж «НОВОСТЬ» и запрещает бейдж «СРОЧНО».
- Design и photo-review стали обязательными машинными gates; сырой RSS-кадр больше не может уйти вместо карточки.
- Publish идемпотентен по `publish-result.json`, резервирует URL перед отправкой и освобождает резерв при ошибке.
- JSON и `.env` пишутся атомарно; `.env` имеет права 600, SQLite работает с WAL и busy timeout.
- RSS загружаются параллельно, кэшируются на 10 минут и не скачиваются второй раз для расширенного окна.
- HTML статьи переиспользуется между photo и copy; старые run-папки чистятся после 2 дней с сохранением последних пяти.

## Ещё можно

- Если оба вызова Kie подряд заканчиваются таймаутом, карточка всё ещё собирается Pillow. Код повторяет задачу один раз. Второй таймаут подряд стоит смотреть по статусу Kie, не увеличивая ожидание выпуска.
- Nano Banana иногда копирует лишний элемент контент-борда. Визуальный review остаётся обязательным; автоматическое компьютерное зрение пока не добавлено.
- Репозитория git нет, поэтому фиксер не пушит правки на GitHub.
- Голос Gemini на сухой жалобе иногда пишет опрос. Сейчас такой опрос обнуляет роль. Промпт можно сузить, чтобы опрос не рождался.
- Отказ искать или покупать игрока без суммы больше не получает шаблон transfer. Обзор сезона с полем action=transfer и без отказа всё ещё может взять чужой макет.
- Исходники фото часто 1200×630 или меньше. В квадрате 600×600 края кадра обрезаются. Имеет смысл заранее выбирать кадр, где лицо ближе к центру.
- Статический контент-борд KIE пока загружается на каждый новый task. Кэш URL потребует подтверждённого срока жизни ссылок Kie.
- Copy и voice остаются двумя вызовами Gemini. Объединять их рискованно: комментарий — отдельное редакционное решение.
- Повторная проверка похожего сюжета перед publish пока атомарна только для точного URL; для параллельных разных URL одного события нужна отдельная таблица reservations по `event_key`.

# Где ломается этот пайплайн

- Публикация без PASS критика и `validate_post.py --require-critic`.
- Отправка сообщения, пока `now` внутри чёрного часа рекламы.
- Слот «примерно в 12» вместо `schedule_date` ровно на минуту перебития.
- Повтор уже выходившей новости: память смотрит URL, похожий заголовок и тот же матч.
- Чужой клубный emoji. Набор `futbol_klub` нельзя ставить, если тег emoji не совпал с клубом новости.
- Custom emoji ботом в канал без дополнительного username на Fragment. Для канала нужен `PUBLISH_BACKEND=user` и Premium-сессия либо Fragment.
- Пустой каталог emoji. Сначала `python3 scripts/sync_emoji.py`.
- Рекламный канал не прочитан. Это стоп, а не «рекламы нет».
- Секреты в handoff, логах и git.
- Правка только `.cursor/agents` без `agents/` или без `scripts/sync_cursor_tree.py`.
- Один агент пишет новость сам, без ролей.
- Новость пересказана заново вместо близкого русского перевода.
- Комментарий дописан внутрь новости, а не ролью fn-voice.
- Выпуск закончился без фиксера или роль не сдала `report_difficulty.py`.
- Push ушёл с `.env`, базой новостей или токеном в diff.
